## Decisiones de diseno
- **Cross** como icono de Cementerio (no existe Tombstone en lucide-react)
- **Save** (disquette) para Registro de Fallecido — connotacion de guardar datos
- **ClipboardPen** para Orden de Trabajo — documento editable
- **UserSearch** para Buscar por Fallecido — busqueda de persona
- **FileStack** para Documentos — expediente digital
- **Backend real completo** — 18 modelos, 3 controladores, 3 requests, 11 seeders, 28 migraciones, 29 rutas. Unicas paginas mock pendientes: Documentos y Reportes
- **Permiso `cementerio`** — controla visibilidad del sidebar completo. Sub-permisos `cementerio-*` controlan items individuales con backward compat
- **OtDetalleModal con fetch JSON** — en vez de pasar datos como props, se fetchea al abrir el modal, evita duplicar datos de OT en memoria
- **EditarFallecidoModal compartido** — mismo componente en RegistroFallecido y ConsultarUbicaciones para mantener consistencia al editar
- **ConsultarUbicaciones usa fetch JSON** — en vez de props Inertia, para evitar recarga completa de pagina al aplicar filtros
- **BuscarOt recibe OTs como props** — todas las OTs al cargar pagina, filtros client-side (suficiente para el volumen esperado)
- **ImprimirOt standalone** — sin AppLayout, con `@page legal`, `window.print()` automatico, evita imprimir sidebar/navbar
- **Fechas DD-MM-YYYY sin timezone** — parseo manual `[y,m,d]` → `d-m-y` en vez de `new Date()` que depende del navegador
- **ExpedienteModal propio** — complejidad alta (3 tabs, timeline), pendiente de conectar a BD
- **Cuotas generadas automaticamente** — al crear OT con forma_pago y numero_cuotas, se distribuye el total equitativamente (residuo en primeras cuotas), vencimiento a 30d escalonado
- **Pago simple vs mixto** — PagarCuotaModal soporta pago simple (un metodo) o mixto (varios metodos en una cuota) via transaccion DB
- **ComprobantePago standalone** — misma estrategia que ImprimirOt: sin AppLayout, `@page legal`, `window.print()` automatico, evita imprimir sidebar
- **nacionalidades.ts separado** — archivo propio en `lib/` en vez de mockData.ts, usado compartidamente por RegistroFallecido y EditarFallecidoModal
- **verificarRut endpoint** — JSON simple que evita duplicados de RUT en el formulario de registro de fallecidos

## Critical Context
- **Encoding:** Solo el `edit` tool o `[System.IO.File]::WriteAllText(path, content, [System.Text.UTF8Encoding]::new($false))` son seguros. PowerShell `Set-Content` escribe UTF-16 corrompiendo tildes/Ñ.
- **Permisos:** `permisos.includes('cementerio')` controla sidebar completo. Sub-permisos `cementerio-*` controlan items individuales. Backward compat: si tiene `cementerio` pero ningun `cementerio-*`, se muestran todos.
- **Toast:** `useToastContext().addToast({ title, description?, variant })`.
- **ConfirmDialog:** `Swal.fire({ title, text, icon, showCancelButton, confirmButtonColor, confirmButtonText })`.
- **DataTable onRowClick:** usado en ConsultarUbicaciones (detalle ubicacion).
- **Iconos:** Cross (Cementerio), Save (Registro), Weight (Deudores), ClipboardPen (OT), UserSearch (Buscar Fallecido), MapPin (Ubicaciones), List (Consultar), FileStack (Documentos), BarChart3 (Reportes), Plus/Search (subitems).
- **Fechas:** Parseo manual `[y,m,d]` → `d-m-y` en todas las paginas, evitar `new Date()`.
- **Impresion:** Pagina standalone sin AppLayout, `@page { size: legal; margin: 0.75cm }`, `window.print()` automatico.
- **OtDetalleModal:** Fetch JSON a `/cementerio/ot/{numero}/detalle` al abrirse, datos no persistentes en padre.
- **EditarFallecidoModal:** PUT via Inertia `router.put`, callback `onSuccess` opcional para refrescar lista padre.
- **PagarCuotaModal:** Pago simple (monto + metodo_pago_id) o mixto (array pagos_mixtos con metodo_pago_id + monto) via transaccion DB. Estados: pendiente → parcial → pagada.
- **ComprobantePago:** Pagina standalone sin AppLayout, `@page size: legal`, `window.print()` automatico. Datos OT + cuota + metodos de pago (mixtos desglosados).
- **verificarRut:** JSON endpoint `/cementerio/verificar-rut?rut=...` retorna `{exists: bool}` para evitar duplicados en registro.
- **nacionalidades.ts:** Archivo separado en `lib/nacionalidades.ts`, importado en RegistroFallecido y EditarFallecidoModal.
- **ModalOT:** Modal legacy con mockOrdenes/mockOTCompleta (convive con OtDetalleModal que usa BD real).
